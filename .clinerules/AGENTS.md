## Agent skills

### Issue tracker

Issues and PRDs live as local markdown files under `.scratch/<NN>-<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage label vocabulary (recorded as `Status:` lines in issue files). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Design system

UI design tokens, component inventory, layout patterns, and conventions live in `DESIGN.md`. See it before creating or modifying Blade components or Tailwind styles.
